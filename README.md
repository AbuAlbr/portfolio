# Abdulbari Abdullah Mulla - Portfolio

A modern, responsive portfolio website built with vanilla HTML, CSS, and JavaScript.

## Features

- 🌙 Premium dark theme with glassmorphism design
- ✨ Smooth scroll-triggered animations
- 🎨 Animated particle background
- ⌨️ Typing effect for dynamic titles
- 📱 Fully responsive design
- 🔍 SEO optimized
- ♿ Accessible with proper ARIA labels

## Tech Stack

- HTML5 (Semantic)
- CSS3 (Custom Properties, Glassmorphism, Animations)
- JavaScript (Intersection Observer, Canvas API)
- Google Fonts (Inter)
- Font Awesome 6

## Deployment

This site is deployed via GitHub Pages with a custom domain.

## Setup

1. Clone the repository
2. Open `index.html` in your browser
3. For custom domain: update the `CNAME` file with your domain
